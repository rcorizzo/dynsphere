# DynSphere: Pendulum-Based Anomaly Detection

This repository contains the code, synthetic benchmark, experiment runners, result
artifacts, and LaTeX source for the DynSphere paper. DynSphere studies anomaly
detection for multivariate sequences where abnormality is defined by invalid
trajectory dynamics rather than by pointwise feature rarity alone.

## Repository Structure

- `pendulum_detector.py`: standalone multi-concept pendulum detector.
- `neural_baselines.py`: autoencoder, window-kNN, forecasting MLP, DeepSVDD, PendulumSeqAE, and EnhancedPendulum implementations.
- `range_metrics.py`: AUROC/AUPRC helpers and VUS wrapper/fallback logic.
- `generate_pendulum_dataset.py`: synthetic benchmark generator.
- `run_benchmarks.py`: synthetic benchmark runner.
- `benchmarks/tsb_ad_m/`: TSB-AD-M download, execution, and analysis scripts.
- `benchmarks/real_world_datasets/`: BATADAL, HAI-20.07, PowerSystem, and related real-world dataset experiments.
- `data/contextual/`: contextual-only synthetic train/test split used in the paper.
- `results/`: synthetic benchmark result JSON files.
- `paper/`: IEEE LaTeX source, bibliography, figure-generation script, and compiled PDF.

## Dataset Redistribution and Attribution

The synthetic contextual benchmark in `data/contextual/` is generated by this
project and is the only dataset intended to be committed with the code. Raw
third-party datasets are excluded by `.gitignore`; use the download commands
below to recreate the expected local layout.

Third-party sources used in the paper:

- BATADAL: original files are available from `https://www.batadal.net/data.html`.
  The BATADAL page asks users to cite Taormina et al., "The Battle of the
  Attack Detection Algorithms: Disclosing Cyber Attacks On Water Distribution
  Networks", Journal of Water Resources Planning and Management, 2018. The
  BATADAL website footer states a Creative Commons Attribution 4.0 license.
- HAI-20.07: files are available from `https://github.com/icsdataset/hai` and
  the Kaggle HAI Security Dataset page. The Kaggle data card lists CC BY-SA 4.0.
  Cite Shin et al., "HAI 1.0: HIL-Based Augmented ICS Security Dataset", 2020.
- PowerSystem: public source files are available from the Mississippi
  State/Oak Ridge ICS dataset pages. Because no explicit redistribution license
  was found in the dataset README, the repository documents download/preparation
  steps instead of redistributing raw files.
- TSB-AD-M: use the benchmark download script. TSB-AD-M points users back to
  original source-family licenses, so the raw archive is not mirrored here.

## Environment

The experiments were run with Python 3.9 on CPU.

Install the core dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Official VUS metrics require the optional `vus` package. One reproducible way to
run with VUS is:

```bash
uv run --with numpy --with pandas --with scikit-learn --with pyod --with torch --with vus python <script.py>
```

## Synthetic Contextual Benchmark

The contextual benchmark contains temporal trajectories. Each `entity_id` is one
sequence ordered by `time`. The observed input features are `x_00` through
`x_11`. Latent/debug columns such as `theta`, `phi`, `theta_dot`, `phi_dot`,
`energy`, `regime_id`, and `regime_name` are not used as detector inputs.

Regenerate the contextual split:

```bash
python3 generate_pendulum_dataset.py \
  --out-dir data/contextual \
  --name pendulum_contextual \
  --anomaly-profile contextual
```

Run the contextual benchmark with neural and pendulum-family methods:

```bash
python3 run_benchmarks.py \
  --train data/contextual/pendulum_contextual_train.csv \
  --test data/contextual/pendulum_contextual_test.csv \
  --include-neural \
  --include-vus \
  --out results/contextual_updated_pendulum_seqae_results.json
```

Run the contextual PyOD/static baselines with VUS:

```bash
python3 run_benchmarks.py \
  --train data/contextual/pendulum_contextual_train.csv \
  --test data/contextual/pendulum_contextual_test.csv \
  --include-vus \
  --out results/contextual_pyod_vus_results.json
```

## Public Source-Family Experiments

The paper reports complete-source TSB-AD-M runs for MSL, SMAP, and SMD, plus
real-world datasets BATADAL, HAI-20.07, and PowerSystem.

Download TSB-AD-M. The archive is written under `benchmarks/tsb_ad_m/data/`,
which is ignored by git:

```bash
python3 benchmarks/tsb_ad_m/download_tsb_ad_m.py
```

Download BATADAL and HAI-20.07 into the expected local paths. These files are
also ignored by git; the commands make the experiments reproducible without
redistributing third-party data:

```bash
python3 benchmarks/real_world_datasets/download_real_world_datasets.py --dataset batadal
python3 benchmarks/real_world_datasets/download_real_world_datasets.py --dataset hai_20_07
```

PowerSystem is not redistributed. To reproduce that row, download the public
PowerSystem dataset archive and README:

```bash
python3 benchmarks/real_world_datasets/download_real_world_datasets.py --dataset power_system
```

Then extract the archive and prepare:

```text
benchmarks/real_world_datasets/data/power_system/binary/combined_binary.csv
```

with the binary labels in the `marker` column. The paper command below assumes
that file exists.

Run the main complete-source methods on MSL, SMAP, and SMD:

```bash
python3 benchmarks/tsb_ad_m/run_tsb_ad_m.py \
  --methods iforest hbos copod lof knn forecast_mlp window_knn pendulum pendulum_seqae enhanced_pendulum \
  --include-sources MSL SMAP SMD \
  --limit 0 \
  --fit-mode all \
  --include-vus \
  --out-dir benchmarks/tsb_ad_m/results_msl_smap_smd_paper
```

Run AutoEncoder for the same sources:

```bash
python3 benchmarks/tsb_ad_m/run_tsb_ad_m.py \
  --methods static_ae \
  --include-sources MSL SMAP SMD \
  --limit 0 \
  --fit-mode all \
  --include-vus \
  --out-dir benchmarks/tsb_ad_m/results_static_ae_table2_official_vus
```

Run DeepSVDD with the lower-epoch configuration used in the paper:

```bash
python3 benchmarks/tsb_ad_m/run_tsb_ad_m.py \
  --methods deep_svdd_kmeans \
  --include-sources MSL \
  --limit 0 \
  --fit-mode all \
  --include-vus \
  --out-dir benchmarks/tsb_ad_m/results_deep_svdd_kmeans_msl_official_vus

python3 benchmarks/tsb_ad_m/run_tsb_ad_m.py \
  --methods deep_svdd_kmeans \
  --include-sources SMAP SMD \
  --limit 0 \
  --fit-mode all \
  --include-vus \
  --out-dir benchmarks/tsb_ad_m/results_deep_svdd_kmeans_smap_smd_official_vus
```

Run the real-world datasets. The real-world dataset runner processes
one dataset per command:

```bash
python3 benchmarks/real_world_datasets/run_real_world_datasets.py \
  --dataset BATADAL \
  --train benchmarks/real_world_datasets/data/batadal/BATADAL_dataset03.csv \
  --test benchmarks/real_world_datasets/data/batadal/BATADAL_dataset04.csv \
  --train-label ATT_FLAG \
  --test-label ATT_FLAG \
  --max-train-rows 20000 \
  --max-test-rows 30000 \
  --methods pendulum enhanced_pendulum pendulum_seqae forecast_mlp window_knn static_ae deep_svdd_kmeans iforest hbos copod lof knn \
  --include-vus \
  --out benchmarks/real_world_datasets/results/batadal_full_vus.csv

python3 benchmarks/real_world_datasets/run_real_world_datasets.py \
  --dataset HAI-20.07 \
  --train benchmarks/real_world_datasets/data/hai_20_07/train1.csv.gz \
  --test benchmarks/real_world_datasets/data/hai_20_07/test1.csv.gz \
  --train-label attack \
  --test-label attack \
  --max-train-rows 20000 \
  --max-test-rows 30000 \
  --methods pendulum enhanced_pendulum pendulum_seqae forecast_mlp window_knn static_ae deep_svdd_kmeans iforest hbos copod lof knn \
  --include-vus \
  --out benchmarks/real_world_datasets/results/hai_20_07_full_vus.csv

python3 benchmarks/real_world_datasets/run_real_world_datasets.py \
  --dataset PowerSystem \
  --train benchmarks/real_world_datasets/data/power_system/binary/combined_binary.csv \
  --test benchmarks/real_world_datasets/data/power_system/binary/combined_binary.csv \
  --train-label marker \
  --test-label marker \
  --max-train-rows 20000 \
  --max-test-rows 30000 \
  --methods pendulum enhanced_pendulum pendulum_seqae forecast_mlp window_knn static_ae deep_svdd_kmeans iforest hbos copod lof knn \
  --include-vus \
  --out benchmarks/real_world_datasets/results/power_system_full_vus.csv
```

The `--max-train-rows` and `--max-test-rows` arguments generate the subsampled
versions used in the paper at run time. No derived third-party CSV needs to be
committed.

Current Table II interpretation:

- DeepSVDD is strongest on MSL.
- EnhancedPendulum is strongest on SMAP and SMD.
- PendulumSeqAE is strongest on BATADAL.
- Pendulum is strongest on HAI-20.07 and PowerSystem.
- EnhancedPendulum has the best AUROC rank sum across the six public rows.
