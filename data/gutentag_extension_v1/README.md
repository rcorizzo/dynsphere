# Generated GutenTAG examples

These 18 synthetic cases were generated from this project's configuration
using TimeEval/GutenTAG 1.5.0. They contain generated signals with controlled
injections, with no real third-party observations. The generation seeds are
101, 102, and 103. Each case contains a normal training CSV and a labeled
test CSV. `native_manifest.json` records their relative paths and SHA256
digests; `generation_config.json` records the mechanisms and settings.
